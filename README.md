# 🎬 AutoClip: สตูดิโอทำหนังสั้นแอนิเมชัน AI อัตโนมัติ

รันบน Google Colab + Google Drive · เปิดเว็บผ่าน Cloudflare Tunnel (ฟรี) · เขียนบทและพากย์เสียงผ่าน OpenRouter

```
หัวข้อ/สกิล → AI เขียนบท → (ตรวจบท) → พากย์เสียง → ตัดต่อภาพ/คลิปจาก Drive → ซับไทย + เพลง → final.mp4 ลง Drive
```

## ขั้นที่ 2: โฟลเดอร์ใน Google Drive (สร้างให้อัตโนมัติ)

ตอนรันช่อง 1 ระบบจะสร้างโฟลเดอร์นี้ให้เอง พร้อมใส่สกิลตัวอย่าง:

```
My Drive/AutoClip/
├─ skills/           ← ใส่สกิลของคุณตรงนี้
│   └─ example-anime/SKILL.md
├─ projects/         ← 1 เรื่อง = 1 โฟลเดอร์ (เว็บสร้างให้)
│   └─ ชื่อเรื่อง/
│       ├─ input/    ← ภาพ/คลิปต้นฉบับของเรื่องนี้
│       ├─ music/    ← เพลงประกอบ (ไม่บังคับ)
│       ├─ bible.md  ← ข้อมูลตัวละคร (AI อัปเดตเอง)
│       └─ ep01/ ep02/ …  ← บท, เสียง, ซับ, final.mp4
├─ fonts/            ← ใส่ไฟล์ฟอนต์ .ttf ได้ (ไม่บังคับ)
└─ settings.json     ← ตั้งค่า (แก้ในเว็บ)
```

โค้ดอยู่ที่ GitHub ส่วนข้อมูลทั้งหมดอยู่ใน Drive ของคุณ (ไม่ขึ้น GitHub)

## ขั้นที่ 3: ซ่อน API key ด้วย Colab Secrets 🔑 (สำคัญ)

**ห้ามพิมพ์ key ลงในโค้ดหรือในเว็บ** ใช้ Secrets เท่านั้น เพราะ Secrets ไม่ติดไปกับไฟล์ notebook เวลาแชร์

1. ใน Colab คลิกไอคอน **🔑 (Secrets)** ที่แถบซ้าย
2. กด **+ Add new secret** แล้วใส่ 2 ตัวนี้

| Name | Value | หมายเหตุ |
|---|---|---|
| `OPENROUTER_API_KEY` | `sk-or-v1-...` | key จาก https://openrouter.ai/settings/keys |
| `AUTOCLIP_PASSWORD` | ตั้งเอง เช่น `mysecret2026` | รหัสเข้าเว็บ ป้องกันคนอื่นมาใช้ credit ของคุณ |

3. **เปิดสวิตช์ Notebook access** ของทั้ง 2 ตัว (ถ้าไม่เปิด โค้ดจะอ่านไม่ได้)

> ถ้าคุณเคยใส่ OpenRouter key ไว้ใน Secrets ด้วยชื่ออื่น ให้เปลี่ยนชื่อเป็น `OPENROUTER_API_KEY` ให้ตรง

**แนะนำเรื่อง credit:** ที่ openrouter.ai/settings/keys ตั้ง **Credit limit** ให้ key นี้ (เช่น $5) กันค่าใช้จ่ายบานปลาย

## ขั้นที่ 4: รัน

กด **Runtime → Run all** (หรือ ▶ ทีละช่อง 1 → 2 → 3 → 4)

- ช่อง 1 จะขอสิทธิ์เข้า Drive → กด **Connect to Google Drive** → เลือกบัญชี → Allow
- ช่อง 4 จะแสดงลิงก์ประมาณนี้ `https://xxxx-xxxx.trycloudflare.com` → คลิกเปิด → ใส่รหัสผ่าน

⚠️ **ข้อจำกัดของ Colab ฟรี**
- ต้องเปิดแท็บ Colab ค้างไว้ ถ้าปิดแท็บหรือไม่มีการใช้งานนาน (~90 นาที) Colab จะตัดการเชื่อมต่อ และรันได้นานสุดประมาณ 12 ชม.
- **ลิงก์เว็บเปลี่ยนทุกครั้ง**ที่รันช่อง 4 ใหม่
- ถ้าโดนตัดกลางงาน: รันช่อง 1-4 ใหม่ → เมนู "สั่งงาน" → กด **▶ ทำต่อ** ระบบจะใช้บทและเสียงที่ทำไว้แล้วใน Drive ต่อเลย ไม่เสีย credit ซ้ำ

## วิธีใช้งานเว็บ (หน้าเดียวจบ)

```
┌ แถบบน: เครดิตฟรีที่เหลือ · 📚 คลังข้อความ · 🎬 งานของฉัน · ⚙️ ตั้งค่า
├ เทมเพลต: ค้นหา / กรองตามแท็ก / การ์ด → "ใช้เทมเพลตนี้"
└ แถบพิมพ์ (ด้านล่าง): พิมพ์ไอเดียหรือวางบท → เลือกตัวเลือก → สร้าง
```

**ตัวเลือกในแถบพิมพ์**
| ปุ่ม | ความหมาย |
|---|---|
| Claude เขียนบท / เขียนบทเอง | Claude เขียนจากไอเดีย (ทำตามเทมเพลตที่เลือก) หรือใช้บทที่คุณวางเอง (1 บรรทัด = 1 ฉาก, บรรทัดแรก `# ชื่อตอน`) |
| ⏱ 10-90 วิ | ความยาวคลิป (ระบบคิดจำนวนฉากให้ ~6 วิ/ฉาก) |
| มาตรฐาน / HD / FHD | 540p / 720p / 1080p |
| ▯ 9:16 | กดสลับ 9:16 → 16:9 → 1:1 |
| 🔊 มีเสียง / 🔇 ไม่มีเสียง | ปิดเสียง = คลิปซับอย่างเดียว (ฟรี เร็ว) |
| ☐ ลายน้ำ | ใส่ข้อความมุมขวาบน (ตั้งข้อความใน ⚙️ ตั้งค่า) |
| ⚙ เพิ่มเติม | เขียนบทด้วย Claude/AI ฟรี/โมเดลอื่น · ภาพ AI ฟรี/จาก Drive/ไม่มีภาพ · เสียง Edge ฟรี/Gemini |
| ✨ 📚 💾 | ให้ AI คิดไอเดีย · หยิบข้อความจากคลัง · เก็บข้อความลงคลัง |

ปุ่มสร้างจะบอกเองว่า **"สร้าง (ฟรี)"** หรือ **"สร้าง (เสียเครดิต)"**

**งานของฉัน (🎬):** ดูความคืบหน้า, หยุด, ทำงานที่ค้างต่อ, ดู log, ตรวจบท, ดูคลิป, ดาวน์โหลด MP4/SRT

**ทำหลาย EP:** ทำ EP 1 ให้เสร็จก่อน แล้วกด **➕ ทำ EP 2 ต่อ** ที่คลิป (ในงานของฉัน) ระบบใช้เทมเพลต สไตล์ ตัวละคร และการตั้งค่าเดิม ให้ AI คิดแค่บท EP ใหม่ต่อจากเรื่องเดิม กดต่อไปได้เรื่อยๆ (EP 3, 4, …)
- ก่อนทำ EP ใหม่ ระบบสรุปตัวละคร/เรื่องเดิมไว้ใน `bible.md` (ใช้ AI +1 ครั้ง) เพื่อให้เรื่องต่อเนื่อง ส่วนคลิปเดี่ยวไม่เสียเพิ่ม
- EP 1 ที่ใช้ **เขียนบทเอง** ก็กดทำ EP ต่อได้ (EP ต่อไปให้ AI เขียน)

**เทมเพลต:** กด "+ สร้างเทมเพลต" แล้ววางสกิลของคุณ หรือวางไฟล์ `SKILL.md` ใน Drive `AutoClip/skills/<ชื่อ>/` · คลิกภาพการ์ดเพื่อดู/แก้ · ใส่ภาพปกได้โดยวาง `cover.jpg` ในโฟลเดอร์เดียวกัน

หัวไฟล์ SKILL.md (ไม่บังคับ):
```markdown
---
name: อนิเมะผจญภัย
description: แอ็กชันสดใส จบด้วยปมค้าง
tags: anime, series
duration: 30
quality: hd
aspect: 9:16
image_style: anime style, vibrant colors, soft lighting
---
(คำสั่งเขียนบท…)
```

## ทำให้ฟรีที่สุด 💸

| ส่วน | ฟรี | เสียเงิน |
|---|---|---|
| เขียนบท | **เขียนบทเอง** (ฟรี 100%) หรือ **AI ฟรี** (`openrouter/free` ~50 ครั้ง/วัน) | **Claude Haiku 5.5** (ค่าเริ่มต้น ~$0.001/EP) · Claude Sonnet 5.5 · โมเดลอื่น |
| ภาพ | **AI สร้าง (Pollinations)** ไม่ต้องมี key · หรือภาพของคุณจาก Drive | – |
| เสียง | **Edge TTS** หรือปิดเสียง | Gemini 3.8 Flash TTS |
| ตัดต่อ | ffmpeg บน Colab ฟรี | – |

ข้อควรรู้
- AI ฟรีของ OpenRouter: ประมาณ 50 ครั้ง/วัน (1 ตอน ≈ 1-2 ครั้ง) ถ้าเคยเติมเงินครบ $10 จะได้ 1,000 ครั้ง/วัน · **ถ้ายอดเครดิตติดลบ โมเดลฟรีก็ใช้ไม่ได้**
- ภาพฟรี Pollinations: ช้า ~15 วิ/ภาพ, อาจมีโลโก้เล็ก, **แผนฟรีห้ามใช้เชิงพาณิชย์** ถ้าจะหารายได้ ให้ใช้ภาพของคุณเอง (จาก Drive)
- บทจาก Claude/แชทอื่น: ให้แชทเขียนบท 1 บรรทัด = 1 ฉาก แล้ววางในโหมด **เขียนบทเอง** = ฟรีทั้งคลิป

## แก้ปัญหา
| อาการ | วิธีแก้ |
|---|---|
| `ไม่พบ OPENROUTER_API_KEY` | เช็คชื่อ secret ให้ตรงตัวพิมพ์ + เปิด Notebook access แล้วรันช่อง 3-4 ใหม่ |
| `เรื่องนี้มีงานค้างอยู่แล้ว` | รอ EP ก่อนหน้าเสร็จ แล้วค่อยกด ทำ EP ต่อ |
| `เครดิต OpenRouter ไม่พอ` / 402 | ⚙ เพิ่มเติม → เขียนบทด้วย **AI ฟรี** หรือใช้ **เขียนบทเอง** และเสียง **Edge** |
| `โมเดลฟรีถูกจำกัด` / 429 | ใช้ฟรีครบโควตาวันนี้ รอวันถัดไป หรือใช้ **เขียนบทเอง** |
| `HTTP 400` model not found | ชื่อ model ผิด → ดูชื่อที่ถูกที่ openrouter.ai/models แล้วแก้ในตั้งค่า |
| เปิดลิงก์แล้ว error 502/1033 | รอ 20 วินาทีแล้วรีเฟรช หรือรันช่อง 4 ใหม่ |
| ซับเป็นสี่เหลี่ยม | รันช่อง 2 (ติดตั้งฟอนต์ไทย) ใหม่ หรือใส่ฟอนต์ .ttf ใน `AutoClip/fonts` แล้วตั้งชื่อฟอนต์ในตั้งค่า |
| ใส่ไฟล์ใน Drive แล้วเว็บไม่เห็น | Drive ใช้เวลา sync 1-2 นาที รอแล้วรีเฟรช |
| ดู error ละเอียด | ช่อง 5 ใน notebook หรือปุ่ม 📜 log ในเมนูสั่งงาน |

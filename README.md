# 🎬 AutoClip: สตูดิโอทำหนังสั้นแอนิเมชัน AI อัตโนมัติ

รันบน Google Colab + Google Drive · เปิดเว็บผ่าน Cloudflare Tunnel (ฟรี) · เขียนบทและพากย์เสียงผ่าน OpenRouter

```
หัวข้อ/สกิล → AI เขียนบท → (ตรวจบท) → พากย์เสียง → ตัดต่อภาพ/คลิปจาก Drive → ซับไทย + เพลง → final.mp4 ลง Drive
```

## ขั้นที่ 2: โฟลเดอร์ใน Google Drive (สร้างให้อัตโนมัติ)

ตอนรันช่อง 1 ระบบจะสร้างโฟลเดอร์นี้ให้เอง พร้อมใส่สกิลตัวอย่าง:

```
My Drive/AutoClip/
├─ skills/           ← ใส่สกิลของคุณตรงนี้
│   └─ example-anime/SKILL.md
├─ projects/         ← 1 เรื่อง = 1 โฟลเดอร์ (เว็บสร้างให้)
│   └─ ชื่อเรื่อง/
│       ├─ input/    ← ภาพ/คลิปต้นฉบับของเรื่องนี้
│       ├─ music/    ← เพลงประกอบ (ไม่บังคับ)
│       ├─ bible.md  ← ข้อมูลตัวละคร (AI อัปเดตเอง)
│       └─ ep01/ ep02/ …  ← บท, เสียง, ซับ, final.mp4
├─ fonts/            ← ใส่ไฟล์ฟอนต์ .ttf ได้ (ไม่บังคับ)
└─ settings.json     ← ตั้งค่า (แก้ในเว็บ)
```

โค้ดอยู่ที่ GitHub ส่วนข้อมูลทั้งหมดอยู่ใน Drive ของคุณ (ไม่ขึ้น GitHub)

## ขั้นที่ 3: ซ่อน API key ด้วย Colab Secrets 🔑 (สำคัญ)

**ห้ามพิมพ์ key ลงในโค้ดหรือในเว็บ** ใช้ Secrets เท่านั้น เพราะ Secrets ไม่ติดไปกับไฟล์ notebook เวลาแชร์

1. ใน Colab คลิกไอคอน **🔑 (Secrets)** ที่แถบซ้าย
2. กด **+ Add new secret** แล้วใส่ 2 ตัวนี้

| Name | Value | หมายเหตุ |
|---|---|---|
| `OPENROUTER_API_KEY` | `sk-or-v1-...` | key จาก https://openrouter.ai/settings/keys |
| `AUTOCLIP_PASSWORD` | ตั้งเอง เช่น `mysecret2026` | รหัสเข้าเว็บ ป้องกันคนอื่นมาใช้ credit ของคุณ |

3. **เปิดสวิตช์ Notebook access** ของทั้ง 2 ตัว (ถ้าไม่เปิด โค้ดจะอ่านไม่ได้)

> ถ้าคุณเคยใส่ OpenRouter key ไว้ใน Secrets ด้วยชื่ออื่น ให้เปลี่ยนชื่อเป็น `OPENROUTER_API_KEY` ให้ตรง

**แนะนำเรื่อง credit:** ที่ openrouter.ai/settings/keys ตั้ง **Credit limit** ให้ key นี้ (เช่น $5) กันค่าใช้จ่ายบานปลาย

## ขั้นที่ 4: รัน

กด **Runtime → Run all** (หรือ ▶ ทีละช่อง 1 → 2 → 3 → 4)

- ช่อง 1 จะขอสิทธิ์เข้า Drive → กด **Connect to Google Drive** → เลือกบัญชี → Allow
- ช่อง 4 จะแสดงลิงก์ประมาณนี้ `https://xxxx-xxxx.trycloudflare.com` → คลิกเปิด → ใส่รหัสผ่าน

⚠️ **ข้อจำกัดของ Colab ฟรี**
- ต้องเปิดแท็บ Colab ค้างไว้ ถ้าปิดแท็บหรือไม่มีการใช้งานนาน (~90 นาที) Colab จะตัดการเชื่อมต่อ และรันได้นานสุดประมาณ 12 ชม.
- **ลิงก์เว็บเปลี่ยนทุกครั้ง**ที่รันช่อง 4 ใหม่
- ถ้าโดนตัดกลางงาน: รันช่อง 1-4 ใหม่ → เมนู "สั่งงาน" → กด **▶ ทำต่อ** ระบบจะใช้บทและเสียงที่ทำไว้แล้วใน Drive ต่อเลย ไม่เสีย credit ซ้ำ

## วิธีใช้งานเว็บ (ทุกเมนู)

| เมนู | ทำอะไร |
|---|---|
| 📊 **แดชบอร์ด** | สถานะ key/ffmpeg, งานที่กำลังรัน, ค่าใช้จ่าย, คลิปล่าสุด |
| 📁 **โปรเจกต์** | สร้างเรื่องใหม่ (มี **popup เลือกสกิล**), เปลี่ยนสกิลได้ทุกเมื่อ, อัปโหลดภาพ/คลิป/เพลง, ดูทุกตอน, แก้ bible |
| ⚙️ **สั่งงาน** | เลือกเรื่อง + จำนวนตอน → เริ่ม / ⏹ หยุด / ▶ ทำต่อ / หยุดทั้งหมด / 📝 ตรวจบท / ดู log |
| 🧩 **คลังสกิล** | ดูสกิลทั้งหมด, กด 🔄 โหลดสกิลใหม่ หลังเพิ่มไฟล์ใน Drive |
| 🎬 **ผลงาน** | ดูคลิป, ดาวน์โหลด MP4 และซับ SRT |
| 🔧 **ตั้งค่า** | model, เสียง, สัดส่วนจอ, ซับ, คุณภาพ, โหมดตรวจบท |

### ทำเรื่องแรก
1. **โปรเจกต์ → ＋ สร้างเรื่องใหม่** → เลือกสกิล → ใส่ชื่อเรื่อง (หรือกด ✨ ให้ AI คิดให้) → จำนวนตอน → **สร้างโฟลเดอร์**
2. ใส่ภาพ/คลิปแอนิเมชันลง `projects/ชื่อเรื่อง/input/` (อัปโหลดในเว็บหรือลากใส่ Drive ก็ได้)
   - **ตั้งชื่อไฟล์ให้บอกเนื้อหา** เช่น `mew_running_forest.mp4`, `owl_angry.png` AI จะเลือกไฟล์ให้ตรงกับฉาก
   - ไม่มีไฟล์เลย = ระบบใช้พื้นสีเรียบ + ซับ (ใช้ทดสอบได้)
3. กด **▶ สั่งงาน** ใส่จำนวนตอน → ไปดูความคืบหน้าที่เมนูสั่งงาน
4. เสร็จแล้วได้ `projects/ชื่อเรื่อง/ep01/final.mp4` ใน Drive

### ทำตอนต่อ / ทำเรื่องใหม่
- **ตอนต่อ:** กดสั่งงานเรื่องเดิม ระบบทำตอนถัดไปให้เอง โดยใช้ `bible.md` + สรุปตอนก่อน เพื่อให้เรื่องต่อเนื่อง
- **เกินจำนวนตอนที่วางแผน:** ทำต่อได้ AI จะเขียนเป็นภาคต่อ
- **เรื่องใหม่:** กด ✨ ให้ AI คิดเรื่องใหม่

### ทำตอนเดิมใหม่ (ปุ่ม ↺ ทำใหม่)
| ตัวเลือก | ทำอะไร | เสีย credit |
|---|---|---|
| 1 ตัดต่อใหม่ | ใช้บท+เสียงเดิม (เช่น เปลี่ยนภาพ/ซับ/สัดส่วนจอ) | ไม่เสีย |
| 2 พากย์+ตัดต่อใหม่ | ใช้บทเดิม (เช่น แก้บทแล้ว หรือเปลี่ยนเสียง) | ค่าเสียง |
| 3 ทำใหม่หมด | เขียนบทใหม่ (ของเก่าย้ายไป `_old_epXX_...` ไม่ลบทิ้ง) | ค่าบท+เสียง |

## สกิล

สกิล = ไฟล์ `SKILL.md` ที่บอก AI ว่าจะเขียนบทสไตล์ไหน

```
skills/
└─ ชื่อสกิล/            ← ภาษาอังกฤษ ไม่มีเว้นวรรค
   └─ SKILL.md
```

หัวไฟล์ (ไม่บังคับ แต่ช่วยให้แสดงสวยในเว็บ):
```markdown
---
name: ชื่อที่จะแสดงในเว็บ
description: อธิบายสั้นๆ 1 บรรทัด
---
(เนื้อหาสกิล…)
```
- ระบบส่ง **เฉพาะ SKILL.md** ให้ AI (ไฟล์อื่นในโฟลเดอร์ไม่ถูกส่ง เพื่อประหยัด token)
- เพิ่มหรือแก้สกิลใน Drive แล้วกด 🔄 **โหลดสกิลใหม่** ไม่ต้องรีสตาร์ท
- สกิลที่ดี: บอกโทน โครงเรื่อง ความยาวประโยค และ **ห้ามมีวงเล็บ/คำกำกับในบทพากย์** (TTS จะอ่านออกมาด้วย)

## เสียงพากย์

| ระบบ | ค่าใช้จ่าย | ตั้งค่า |
|---|---|---|
| **Gemini 3.8 Flash TTS** ผ่าน OpenRouter | เสียเงินตามความยาว | Model `google/gemini-3.8-flash-tts` (ถูกกว่า: `google/gemini-3.8-flash-lite-tts`) · เสียง: Kore, Puck, Charon, Aoede, Leda, Orus, Zephyr ฯลฯ |
| **Edge TTS** | ฟรี | `th-TH-PremwadeeNeural` (หญิง), `th-TH-NiwatNeural` (ชาย) |

เลือกเป็นค่าเริ่มต้นได้ในตั้งค่า หรือเลือกแยกเป็นรายเรื่องในหน้าโปรเจกต์

## ประหยัด credit แต่คุณภาพดี
- ค่าเริ่มต้นเขียนบทรอบเดียว (`polish` ปิดไว้) ถ้าบทยังไม่ดีพอ ค่อยเปิด "ขัดเกลาบทรอบ 2"
- เปิด **"หยุดให้ตรวจบทก่อนพากย์"** ถ้าไม่ชอบบท จะได้แก้ก่อนเสียค่าเสียง
- ใช้ Edge TTS (ฟรี) ตอนทดลอง แล้วค่อยเปลี่ยนเป็น Gemini ตอนทำจริง
- ทุกขั้นบันทึกลง Drive พังกลางทางกดทำต่อได้ ไม่ต้องจ่ายซ้ำ
- ตัวเลขค่าใช้จ่ายในเว็บ **นับเฉพาะค่าเขียนบท** ยอดรวมจริง (รวมเสียง) ดูที่ openrouter.ai/activity

## แก้ปัญหา
| อาการ | วิธีแก้ |
|---|---|
| `ไม่พบ OPENROUTER_API_KEY` | เช็คชื่อ secret ให้ตรงตัวพิมพ์ + เปิด Notebook access แล้วรันช่อง 3-4 ใหม่ |
| `HTTP 402` | credit OpenRouter หมด → เติมเงิน หรือเปลี่ยนไปใช้ Edge TTS |
| `HTTP 400` model not found | ชื่อ model ผิด → ดูชื่อที่ถูกที่ openrouter.ai/models แล้วแก้ในตั้งค่า |
| เปิดลิงก์แล้ว error 502/1033 | รอ 20 วินาทีแล้วรีเฟรช หรือรันช่อง 4 ใหม่ |
| ซับเป็นสี่เหลี่ยม | รันช่อง 2 (ติดตั้งฟอนต์ไทย) ใหม่ หรือใส่ฟอนต์ .ttf ใน `AutoClip/fonts` แล้วตั้งชื่อฟอนต์ในตั้งค่า |
| ใส่ไฟล์ใน Drive แล้วเว็บไม่เห็น | Drive ใช้เวลา sync 1-2 นาที รอแล้วรีเฟรช |
| ดู error ละเอียด | ช่อง 5 ใน notebook หรือปุ่ม 📜 log ในเมนูสั่งงาน |

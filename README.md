## วิธีใช้งานเว็บ (หน้าเดียวจบ)

```
┌ แถบบน: เครดิตฟรีที่เหลือ · 📚 คลังข้อความ · 🎬 งานของฉัน · ⚙️ ตั้งค่า
├ เทมเพลต: ค้นหา / กรองตามแท็ก / การ์ด → "ใช้เทมเพลตนี้"
└ แถบพิมพ์ (ด้านล่าง): พิมพ์ไอเดียหรือวางบท → เลือกตัวเลือก → สร้าง
```

**ตัวเลือกในแถบพิมพ์**
| ตัวเลือก | ความหมาย |
|---|---|
| วางบท (ฟรี) / AI เขียนบท | วางบทจาก Claude ในแชท (ฟรี 100%, วางหลาย EP ได้) หรือให้ AI เขียนจากไอเดีย |
| ปุ่มคัดลอก (ในช่องพิมพ์) | คัดลอกคำสั่งสำเร็จรูปไปให้ Claude ในแชทเขียนบท (มีเทมเพลตใส่ให้แล้ว) |
| แถบเลื่อนความยาว | ลากเลือกได้อิสระ 5 วิ – 3 นาที ต่อ EP |
| มาตรฐาน / HD / FHD | 540p / 720p / 1080p (สัดส่วน 9:16 สำหรับ TikTok / Reels เท่านั้น) |
| ซับ (ไอคอน CC) | ซับไทย / ซับอังกฤษ / ไทย + อังกฤษ (2 บรรทัด) / ไม่มีซับ · ดาวน์โหลดไฟล์ซับ .srt แยกภาษาได้ |
| เสียงพากย์ | ค่าเริ่มต้น = เสียงของเทมเพลต (ใช้ต่อทุก EP) เปลี่ยนได้ทั้งตอนสร้างและตอนทำ EP ต่อ |
| สวิตช์ลายน้ำ | ใส่ชื่อช่องมุมขวาบน (ตั้งข้อความที่ ตั้งค่าช่อง) |
| ปรับเพิ่มเติม | AI เขียนบทด้วย, ภาพประกอบ, ความเร็วเสียง, ความเร็ว encode, FPS, ขนาด/ฟอนต์ซับ |

**เปิด/ปิดเสียง:** หลังคลิปเสร็จ เปิดดูคลิป → กด "เสียงเปิด/ปิด" → ดาวน์โหลดแบบมีหรือไม่มีเสียงได้

**สไตล์ภาพ เสียง และองค์ประกอบ มาจากเทมเพลตทั้งหมด** · หน้าที่ของเราคือเขียนบทใหม่แล้วเลือกเทมเพลต

**ปรับแต่ง (ปุ่มไม้กายสิทธิ์ ไม่บังคับ):** สั่งเสริมเฉพาะครั้ง ไม่เปลี่ยนเทมเพลต
| ปุ่ม | ผลจริง |
|---|---|
| ช้าลง นุ่มนวล | เว้นระหว่างฉากนานขึ้น, ภาพซูมช้าลง, เสียงพากย์ช้าลง 10% |
| เพิ่มแสงเงา / สมจริงขึ้น / สีสดขึ้น | เพิ่มคำสั่งภาพ (cinematic lighting, realistic, vibrant) + บอกในบท |
| ภาพนิ่ง ไม่ซูม | ปิดการซูมภาพ |
| สั่งเพิ่มเอง | ใส่ในคำสั่งเขียนบท (และคำสั่งที่คัดลอกให้ Claude) · ถ้าพิมพ์เป็นอังกฤษ จะใช้กับภาพด้วย |

ตั้งไว้ตอนสร้าง = ใช้กับ EP ของเรื่องนั้น · ตอนทำ EP ต่อ เปลี่ยนหรือล้างได้

**ไอคอนเฟือง:** ลายน้ำ (เปิดเป็นค่าเริ่มต้น + ข้อความ)

ปุ่มสร้างจะบอกเองว่า **"สร้าง (ฟรี)"** หรือ **"สร้าง (เสียเครดิต)"**

**งานของฉัน (🎬):** ดูความคืบหน้า, หยุด, ทำงานที่ค้างต่อ, ดู log, ตรวจบท, ดูคลิป, ดาวน์โหลด MP4/SRT

**ทำหลาย EP แบบฟรี (แนะนำ):**
1. EP แรก: แถบพิมพ์ → **วางบท (ฟรี)** → กด **📋** เลือกจำนวน EP → คัดลอกคำสั่ง → วางในแชท Claude
2. ก๊อปบทที่ได้ (กี่ EP ก็ได้) มาวางในแถบพิมพ์ → ปุ่มจะขึ้น **สร้าง 3 EP (ฟรี)** → กด แล้วระบบทำครบทุก EP ต่อคิวให้เอง
3. ทำต่อ: งานของฉัน → คลิปล่าสุด → **➕ ทำ EP ต่อ** → **📋 คัดลอกคำสั่ง** (มีเทมเพลต + เรื่องย่อทุกตอน + บทตอนล่าสุดให้แล้ว) → วางในแชท Claude → วางบทกลับมา → **สร้าง (ฟรี)**
4. ไม่อยากก๊อป: กด **ให้ AI เขียนแทน** (ใช้ AI ฟรี/เสียเงินตามที่ตั้งไว้)

รูปแบบบทที่วาง (ช่องที่ 2-3 ไม่บังคับ):
```
บทพากย์ภาษาไทย | english image prompt | English subtitle
```
ถ้าเลือกซับอังกฤษแต่บทไม่มีช่องที่ 3 ระบบแปลให้ด้วย AI ฟรี (1 ครั้งต่อ EP) · คำสั่งที่คัดลอกให้ Claude จะขอช่องที่ 3 ให้อัตโนมัติ

ตัวอย่าง:
```
# EP 2: ชื่อตอน
บทพากย์ฉาก 1 | english image prompt (ไม่บังคับ)
บทพากย์ฉาก 2 | ...
# EP 3: ชื่อตอน
...
```

**เทมเพลต:** กด "+ สร้างเทมเพลต" แล้ววางสกิลของคุณ หรือวางไฟล์ `SKILL.md` ใน Drive `AutoClip/skills/<ชื่อ>/` · คลิกภาพการ์ดเพื่อดู/แก้ · ใส่ภาพปกได้โดยวาง `cover.jpg` ในโฟลเดอร์เดียวกัน

หัวไฟล์ SKILL.md (ไม่บังคับ):
```markdown
---
name: อนิเมะผจญภัย
description: แอ็กชันสดใส จบด้วยปมค้าง
tags: anime, series
duration: 30
quality: hd
aspect: 9:16
image_style: anime style, vibrant colors, soft lighting
---
(คำสั่งเขียนบท…)
```

## สกิลที่มีเอนจินของตัวเอง (เช่น ละครสั้นดราม่า ตัวการ์ตูน)

สกิลบางตัวมีตัวเรนเดอร์ของตัวเอง ระบบจะ **ให้สกิลวาดแอนิเมชัน · ระบบเราคุมเสียง ลายน้ำ และความคมชัด**

```
skills/<ชื่อสกิล>/
├─ SKILL.md, scripts/, engine/, reference/ ...   ← ของสกิล
└─ autoclip.json                                 ← บอกระบบว่าเรียกสกิลยังไง (engine, requirements, check, render)
```

ใช้งาน:
1. เลือกเทมเพลตที่มีป้าย **มีเอนจิน** → กดปุ่มคัดลอกคำสั่ง → วางในแชท Claude (คำสั่งมีไฟล์อ้างอิงของสกิลครบ)
2. วางคำตอบทั้งก้อน (series.json + epNN.json, กี่ EP ก็ได้) ในแถบพิมพ์ → **สร้าง**
3. ระบบรันตัวตรวจบทของสกิลก่อน ถ้าไม่ผ่านจะแสดง ERROR ให้ก๊อปไปให้ Claude แก้
4. ผ่านแล้วสกิลเรนเดอร์ (ประมาณ 1–3 นาทีต่อคลิป 30 วิ บน CPU) → ระบบใส่ลายน้ำ ปรับความคมชัด เก็บลง Drive
5. ทำ EP ต่อ: ปุ่ม **ทำ EP ต่อ** → คัดลอกคำสั่ง (มี series.json ล่าสุดให้) → วาง epNN.json กลับมา

เสียง: เลือกเสียงผู้บรรยาย/พระเอกได้ในแถบพิมพ์ (Edge ฟรี) และปรับความเร็วเสียงได้ · ตัวละครอื่นใช้เสียงตามที่สกิลกำหนด · หรืออัปไฟล์เสียงพากย์เอง (แยกไฟล์ตามตัวละครได้ กดปุ่มไมค์เพื่อดาวน์โหลดบทพากย์)
ฉากหลังเฉพาะ (ไม่บังคับ): ให้ Claude ส่ง code block ```python``` บรรทัดแรก `# bg: <place_id>` วางมาพร้อมบท

## เสียง ElevenLabs (ไม่บังคับ · เสียเครดิต ElevenLabs)

1. ElevenLabs → **Developers → API Keys → Create** (ติ๊กสิทธิ์ Text to Speech และ Voices: Read)
2. Colab → 🔑 Secrets → Add new secret: ชื่อ `ELEVENLABS_API_KEY` ค่า = key → เปิด **Notebook access** → รันช่องใหม่
3. (ไม่บังคับ) เพิ่มเสียงที่ชอบเข้า **My Voices** — ระบบใช้ My Voices ก่อน ถ้าไม่มีเสียงที่เพศ/วัยตรงตัวละคร จะค้น **Voice Library เสียงภาษาไทย** แล้วเพิ่มเข้าบัญชีให้เอง (ใช้ช่องเสียงของแผน · ข้ามเสียงที่คิดเครดิตแพงกว่าปกติ)
4. ในเว็บ: ช่องเสียงเลือก **ElevenLabs · เลือกเสียงให้อัตโนมัติ** (ค่าเริ่มต้นคือ Edge ฟรี) → วางบทแล้วกดสร้าง **ระบบเลือกเสียงให้ทุกตัวละครเอง** (ปุ่มสร้างบอกเครดิตที่จะใช้) · ดู/เปลี่ยนเสียงรายตัวที่ปุ่ม 👥 **เสียงตัวละคร**

**ระบบเลือกเสียงเองยังไง:** อ่านเพศ/วัยจากเทมเพลต (series.json ของสกิล หรือให้ AI ฟรีอ่านเทมเพลต+บท ครั้งเดียวต่อตัวละคร) → เลือกเสียงที่เข้ากันและไม่ซ้ำกันในเรื่อง → **จำไว้**: เรื่องเดิมใช้เสียงเดิมทุก EP · เรื่องใหม่ในเทมเพลตเดิม ตัวละครชื่อเดิมได้เสียงเดิม ตัวละครใหม่ได้เสียงตามประเภท (ผู้หญิงคนแรก = เสียงเดิมทุกเรื่อง) · ความจำอยู่ที่ `skills/<เทมเพลต>/voices.json`
ไม่มี key ElevenLabs = ใช้ Edge ฟรี โดยแยกตัวละครด้วยระดับเสียงสูง/ทุ้ม (Edge ไทยมีชาย 1 หญิง 2 เสียง)

- โมเดลที่อ่านไทยได้: **v4 Turbo (ค่าเริ่มต้น ถูกสุด)** · v4 (อารมณ์ดีสุด แพง 2 เท่า) · v3 — **Flash / Multilingual v2 ไม่รองรับไทย**
- ระบบใส่ tag อารมณ์ให้จากสีหน้าในบท · ประโยคที่เคยสร้างแล้วเก็บแคชใน Drive ไม่เสียเครดิตซ้ำ
- เสียงตัวละครบันทึกกับเรื่อง ใช้ต่อทุก EP · ตัวละครที่ไม่เลือก = Edge ฟรี
- ElevenLabs พัง (เครดิตหมด/key ผิด) งานจะหยุดพร้อมข้อความ ไม่เรนเดอร์คลิปเงียบ · แก้แล้วกด ทำงานที่ค้างต่อ (ประโยคที่สร้างแล้วไม่คิดซ้ำ)

- AI ฟรีของ OpenRouter: ประมาณ 50 ครั้ง/วัน (1 ตอน ≈ 1-2 ครั้ง) ถ้าเคยเติมเงินครบ $10 จะได้ 1,000 ครั้ง/วัน · **ถ้ายอดเครดิตติดลบ โมเดลฟรีก็ใช้ไม่ได้**
- ภาพฟรี Pollinations: ช้า ~15 วิ/ภาพ, อาจมีโลโก้เล็ก, **แผนฟรีห้ามใช้เชิงพาณิชย์** ถ้าจะหารายได้ ให้ใช้ภาพของคุณเอง (จาก Drive)
- บทจาก Claude/แชทอื่น: ให้แชทเขียนบท 1 บรรทัด = 1 ฉาก แล้ววางในโหมด **เขียนบทเอง** = ฟรีทั้งคลิป

## แก้ปัญหา
| อาการ | วิธีแก้ |
|---|---|
| `ไม่พบ OPENROUTER_API_KEY` | เช็คชื่อ secret ให้ตรงตัวพิมพ์ + เปิด Notebook access แล้วรันช่องใหม่ |
| `เรื่องนี้มีงานค้างอยู่แล้ว` | รอ EP ก่อนหน้าเสร็จ แล้วค่อยกด ทำ EP ต่อ |
| `เครดิต OpenRouter ไม่พอ` / 402 | ⚙ เพิ่มเติม → เขียนบทด้วย **AI ฟรี** หรือใช้ **เขียนบทเอง** และเสียง **Edge** |
| `โมเดลฟรีถูกจำกัด` / 429 | ใช้ฟรีครบโควตาวันนี้ รอวันถัดไป หรือใช้ **เขียนบทเอง** |
| `HTTP 400` model not found | ชื่อ model ผิด → ดูชื่อที่ถูกที่ openrouter.ai/models แล้วแก้ในตั้งค่า |
| เปิดลิงก์แล้ว error 502/1033 | รอ 20 วินาทีแล้วรีเฟรช หรือรันช่องใหม่ |
| ซับเป็นสี่เหลี่ยม | รันช่องใหม่ (ติดตั้งฟอนต์ไทย) หรือใส่ฟอนต์ .ttf ใน `AutoClip/fonts` แล้วตั้งชื่อฟอนต์ในตั้งค่า |
| ใส่ไฟล์ใน Drive แล้วเว็บไม่เห็น | Drive ใช้เวลา sync 1-2 นาที รอแล้วรีเฟรช |
| ดู error ละเอียด | ปุ่ม log ที่การ์ดงาน (งานของฉัน) หรือไฟล์ /content/server.log |

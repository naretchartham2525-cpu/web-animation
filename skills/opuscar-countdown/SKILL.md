# Live Countdown Split-screen  ·  Lemo-Opuscar #03

**หมวด:** สารคดีและตัดต่อ (Edit & Documentary)
**เหมาะกับ:** Launches, Countdowns, Live events
**ลุคของสไตล์:** An edit style, not a look. Real footage of one event with a known zero (a launch, a verdict, a final whistle, polls closing), shown in real time: screen time equals event time, a clock ticks every second, and the screen splits into more and more cells as the moment nears, every cell showing the same second.

## วิธีเขียนบทสำหรับเทมเพลตนี้
- ทุกฉากต้องมีคำบรรยายภาพภาษาอังกฤษที่บรรยายตามลุคด้านบน (วัสดุ สี แสง มุมกล้อง) ให้เหมือนกันทั้งเรื่อง
- เรื่องเดียว เป้าหมายเดียว มีจุดพลิกหนึ่งครั้ง · 3 วินาทีแรกต้องดึงคนดู · ตอนจบย้อนกลับไปหาตอนเปิด
- ใช้คู่มือสไตล์ฉบับเต็มใน STYLE.md ของโฟลเดอร์นี้เป็นหลักเรื่องสี ตัวอักษร จังหวะ และสิ่งที่ห้ามทำ
- ห้ามลอกเรื่อง ตัวละคร หรือช็อตของเดโมต้นฉบับ ("Counting Itself Down")

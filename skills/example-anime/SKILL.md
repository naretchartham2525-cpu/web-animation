# อนิเมะผจญภัย (สกิลตัวอย่าง)

> ไฟล์นี้คือ "สกิล" = คำสั่งที่ AI ต้องทำตามตอนเขียนบท
> สร้างสกิลใหม่: copy โฟลเดอร์นี้ เปลี่ยนชื่อโฟลเดอร์ แล้วแก้เนื้อหา

## โทนเรื่อง
- สดใส อบอุ่น มีมุกเบาๆ เหมาะทุกวัย
- ตัวเอกกล้าหาญแต่ซุ่มซ่าม มีเพื่อนคู่หูที่นิสัยตรงข้าม

## โครงสร้าง 1 ตอน
1. ฉากเปิด: ประโยคแรกต้องดึงคนดูภายใน 3 วินาที (คำถาม/เหตุการณ์แปลก)
2. ปัญหา: ตัวเอกเจออุปสรรค
3. พยายามแก้ แต่พลาด 1 ครั้ง
4. คู่หูช่วย หรือค้นพบสิ่งใหม่
5. จบ: แก้ได้บางส่วน + ทิ้งปมให้อยากดูตอนต่อไป

## กฎการเขียนบทพากย์
- ผู้บรรยายเล่าเรื่องคนเดียว ใช้ภาษาพูดง่ายๆ
- ประโยคสั้น ไม่เกิน 2 บรรทัดต่อฉาก
- ห้ามใส่คำกำกับท่าทางหรือวงเล็บในบทพากย์ (เพราะ TTS จะอ่านออกมาด้วย)
- ช่อง visual ให้บรรยายภาพเป็นภาษาไทยสั้นๆ: ใคร ทำอะไร ที่ไหน มุมกล้อง

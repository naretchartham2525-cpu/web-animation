# Thai Drama Script: Skill เขียนบทละครสั้นแนวตั้งสำหรับ Claude Code

ให้ Claude เขียนซีรีส์ดราม่าสั้นภาษาไทยสำหรับ TikTok, Reels และ Shorts ได้ครบทั้งเรื่อง ได้ออกมาแบบนี้

- **ไบเบิลซีรีส์:** ตัวละครพร้อมลุคสำหรับวาด ฉากพร้อมพรอมต์สร้างภาพฉากหลังด้วย AI และโครงเรื่องทุก EP
- **บททีละช็อต:** ใครพูด พูดอะไร สีหน้า ท่าทาง และฉาก
- **หน้าจอมือถือในเรื่อง:** แชตไลน์ ไลฟ์ รีวิว โพสต์ เอกสาร หมายศาล และระบบพิเศษ
- **ของพร้อมลงคลิป:** ชื่อคลิป (ขึ้นต้นด้วย EP) แฮชแท็ก ข้อความบนปก สปอยล์ตอนหน้า และคำถามท้ายคลิป
- **ไฟล์ทำงานต่อ:** ซับ `.srt` พร้อมเวลาโดยประมาณ ไฟล์ลำดับเสียงพากย์แยกตามคนพากย์ และบทอ่านง่าย `.md`
- **ตัวตรวจบทอัตโนมัติ:** เช็คความยาว สัดส่วนบทพูด ไลน์ซ้ำ และคนพูดที่ไม่อยู่ในฉาก แล้วให้ Claude แก้เองจนผ่าน

มีแนวเรื่องให้เลือก 13 แบบ เช่น เพื่อนบ้านอวดดี ญาติเอาเปรียบ ได้ระบบพิเศษ เชฟถูกโกง ไรเดอร์ถูกดูถูก หัวหน้าขโมยผลงาน แฟนเก่านอกใจ ย้อนเวลา และแฉสายมูปลอม

## เวอร์ชัน 1.2 (18 พ.ย. 2026)

- แก้สีตัวละคร: ซีกเงาของหัวและตัว และแก้มแดง เคยโปร่งใสจนเห็นฉากหลังทะลุ ตอนนี้ทึบเต็มตัว

## เวอร์ชัน 1.1 (18 พ.ย. 2026)

ผู้ซื้อทุกคนได้รับอัปเดตฟรี เวอร์ชันนี้เพิ่ม:

- ตัวละครขยับแบบมีน้ำหนัก: เปลี่ยนท่าแบบเด้งเข้าที่ ยืนถ่ายน้ำหนักซ้ายขวา ไม่แข็งเป็นหุ่น
- โดนผลักแล้วเซถอยหลัง ล้มลงตามแรงโน้มถ่วง เด้งนิดหนึ่งแล้วนอนนิ่ง ถ้าอยู่ชิดขอบจอจะล้มก้นจ้ำเบ้าแทน ตัวไม่หลุดเฟรม
- ท่าเดินและวิ่งเคลื่อนที่จริง เดินเข้าฉาก วิ่งหนีออกจากจอ ไม่ย่ำอยู่กับที่
- ใส่ `then` ให้เปลี่ยนท่ากลางประโยค และ `enter` ให้เดินเข้าจากซ้ายหรือขวา
- แก้ท่าแขนไขว้ ท่ายกมือที่มือหายหลังหัว ท่านั่งที่ดูเหมือนยืน
- รูปร่างอ้วน ผอม กางเกงขายาว ขาสั้น และของ ชุด ท่าใหม่หมวดวันสิ้นโลก

วิธีอัปเดต: ลบโฟลเดอร์ `~/.claude/skills/thai-drama-script` เดิม แล้วทำขั้นตอนติดตั้งด้านล่างใหม่ด้วยไฟล์ zip ใหม่ ซีรีส์ที่เขียนไว้แล้วใช้ต่อได้ทันที

## ติดตั้ง (ดูภาพรวมใน คู่มือติดตั้ง.pdf)

1. ติดตั้งแอป Claude จาก claude.ai/download แล้วล็อกอินด้วยบัญชี Pro
2. สร้างโฟลเดอร์ `drama-work` แล้วลากไฟล์ zip นี้ไปใส่
3. ในแอป เปิดแท็บ **Code** → เลือก **Local** → **Open folder…** → เลือกโฟลเดอร์ `drama-work`
4. วางข้อความนี้แล้วกด Enter: `ติดตั้ง skill จากไฟล์ thai-drama-script.zip ในโฟลเดอร์นี้ ไปไว้ที่ ~/.claude/skills แล้วเปิดอ่าน SKILL.md ข้างใน และทำขั้นตอน Setup ให้ครบ`
5. เปิด session ใหม่ แล้วเริ่มสั่งงานได้เลย

## วิธีใช้

เปิด Claude Code ในโฟลเดอร์ที่จะเก็บงาน แล้วพิมพ์ เช่น

- `เขียนซีรีส์ดราม่าใหม่ 5 ตอน แนวเพื่อนบ้านอวดดี พล็อต: ป้าข้างบ้านจอดรถขวางหน้าบ้านทุกวัน`
- `เขียน EP ต่อไป`
- `EP2 ขอให้ดราม่ากว่านี้ บทพูดเยอะขึ้น`
- `ซีรีส์ใหม่ พระเอกเป็นไรเดอร์ มีระบบพิเศษ ตอนละ 60 วิ`

งานจะถูกเก็บไว้ที่ `drama/<ชื่อซีรีส์>/` ในโฟลเดอร์ที่เปิดอยู่

ดูตัวอย่างงานได้ที่ `examples/chicken_rice_war/` มีทั้งไบเบิลซีรีส์ บท EP1 ซับ และไฟล์เสียงพากย์

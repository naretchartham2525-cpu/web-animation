- บาร์เทนเดอร์

- หมอ / พยาบาล
- ทนาย
- ตำรวจ
- ไรเดอร์ส่งอาหาร
- แม่ค้าออนไลน์
- ชาวประมง
- เกษตรกร / ชาวสวน

## Skill / เก่งอะไร
- ทำอาหารระดับเทพ
- ซ่อมได้ทุกอย่าง
- ผสมเหล้า / ชิมแยกส่วนผสม
- ความจำภาพถ่าย
- อ่านคนจากสีหน้า
- แฮก / เจาะข้อมูล
- ต่อรองเจรจา
- รู้กฎหมาย
- จับโกงบัญชี
- ต่อสู้ป้องกันตัว
- ขายของเก่ง
- แต่งหน้า / ปลอมตัว

## Special trait / ความพิเศษ
- ไม่มี (คนธรรมดา)
- มีระบบพิเศษ (หน้าจอระบบ / ภารกิจ / รางวัล)
- เกิดใหม่ย้อนเวลา
- รู้อนาคต 24 ชม.
- ได้ยินเสียงในใจคน
- เห็นตัวเลขความจริงบนหัวคน
- รวยลับๆ แต่ทำตัวจน

If the special trait is a SYSTEM (ระบบพิเศษ), use `system` phone shots for its notices (see format.md), at most 4 per episode.
